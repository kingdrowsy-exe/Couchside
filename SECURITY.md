# Security

Report security issues privately. Please do not open a public GitHub issue for a vulnerability, and do not include exploit details in a public discussion.

Use GitHub private vulnerability reporting on this repository: Security, then Report a vulnerability. If that is not available, contact the repository owner on GitHub and ask for a private way to send the report.

Couchside stores Plex, Silo, Emby, Xtream, TMDB, and Trakt credentials on the local machine. A report that those credentials can be read by another user or by a web page is in scope.
